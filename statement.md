# Habit Forge - Project Statement

## Project Title

**Habit Forge - A Simple CLI Habit Tracker**

## Project Statement

Habit Forge is a command-line based habit tracking application developed using Python. The purpose of the project is to help users create, manage, and track their daily or weekly habits in a simple and organized way.

The application allows users to add new habits, mark habits as completed, view their habits, track completion dates, and calculate their current streaks. Habit data is stored locally so that users can continue tracking their progress across different sessions.

The project focuses on applying fundamental Python programming concepts such as classes and objects, functions, lists, dictionaries, file handling, JSON data storage, loops, conditional statements, and date manipulation.

## Problem

Many people start good habits but struggle to maintain consistency because they do not have a simple way to monitor their progress.

Existing habit-tracking applications may provide many unnecessary features or require users to create accounts and use complex interfaces. There is a need for a lightweight and beginner-friendly application that provides the basic functionality required to track habits.

## Proposed Solution

Habit Forge provides a simple command-line interface where users can manage their habits and monitor their consistency.

The application provides features such as:

- Creating new habits
- Viewing existing habits
- Marking habits as completed
- Tracking completion dates
- Calculating habit streaks
- Supporting daily and weekly habits
- Saving habit data locally
- Loading saved data when the application starts

## Objectives

The main objectives of Habit Forge are:

1. To develop a simple and easy-to-use habit tracking application.
2. To help users maintain consistency with their habits.
3. To track habit completion and calculate streaks.
4. To store user data persistently using JSON.
5. To implement object-oriented programming concepts in Python.
6. To strengthen practical programming and problem-solving skills.
7. To develop a functional command-line application using Python.

## Scope

The current version of Habit Forge focuses on basic habit management through a command-line interface.

The project includes:

- Habit creation
- Habit management
- Completion tracking
- Daily and weekly frequency
- Streak calculation
- Local JSON-based storage
- Command-line interaction

The project does not currently include a graphical user interface, cloud synchronization, user accounts, or a mobile application.

## Target Users

Habit Forge is designed for:

- Students
- Beginners who want to track personal habits
- Users who prefer simple command-line applications
- Anyone who wants to monitor consistency without a complicated interface

## Technology Used

- **Programming Language:** Python
- **Data Storage:** JSON
- **Interface:** Command Line Interface (CLI)
- **Version Control:** Git and GitHub
- **Development Environment:** VS Code

## Expected Outcome

The expected outcome of the project is a working command-line habit tracker that allows users to manage their habits and monitor their consistency over time.

The project also demonstrates the practical application of Python programming, object-oriented programming, data structures, file handling, and basic software development practices.

## Future Scope

Habit Forge can be extended in the future with features such as:

- Graphical User Interface
- User accounts and authentication
- Database integration
- Habit reminders and notifications
- Progress charts and statistics
- Monthly and yearly reports
- Cloud synchronization

## Conclusion

Habit Forge is a lightweight habit tracking application designed to make habit management simple and accessible. The project combines fundamental Python programming concepts with a practical real-world problem, providing a useful foundation for developing more advanced software applications in the future.
